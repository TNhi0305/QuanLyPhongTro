# Thư mục Hình ảnh Minh họa Dự án

Thư mục này lưu trữ ảnh chụp màn hình ứng dụng di động React Native Expo và cổng quản lý Web phục vụ báo cáo và tài liệu đồ án:

1. `mobile_home_admin.png`: Màn hình Trang chủ Dashboard dành cho Chủ trọ.
2. `mobile_home_tenant.png`: Màn hình Trang chủ dành cho Khách thuê.
3. `mobile_rooms_mvvm.png`: Màn hình Quản lý phòng trọ theo kiến trúc MVVM (`RoomsView`).
4. `mobile_invoices_mvvm.png`: Màn hình Quản lý hóa đơn & Quét mã VietQR thanh toán (`InvoicesView`).
5. `mobile_notifications_mvvm.png`: Màn hình Lịch sử thông báo & Tùy chọn Push Notification (`NotificationsView`).
6. `push_notification_banner.png`: Ảnh chụp Push Notification hiển thị trên thanh thông báo Android/iOS.
7. `unit_test_results.png`: Ảnh chụp kết quả chạy Jest Unit Test đạt 100% PASS.
